# 功能清單與設計決策

範例行程全部做完的功能。新行程預設全保留；使用者不需要的再拿掉（拿掉時連資料常數、CSS、導覽列連結一起清）。

## 桌機版（>640px）
- **首頁 hero**：標題、日期、路線字串、總覽地圖（hover 展開完整比例）。
- **導覽列** `#strip`：每天一格＋各區塊；捲動時 IntersectionObserver 高亮目前區塊。
- **每日區塊**：Day 標題＋天氣小格；左邊時刻表（STOPS 產生，交通段灰色小字）＋雨備說明；右邊路線地圖
  （依交通方式畫線、編號標記＝卡片號碼、有照片的標記是圓形縮圖、重播路線鈕、交通方式圖例）；下方景點卡（依時間排序、號碼對地圖）。
- **景點彈窗**：照片輪播（←→、圓點、滑動）、介紹、chips、`info` 表格（地址電話公休門票）、Google 地圖按鈕、YouTube 內嵌（有載入動畫，`t=` 從某秒開始）。
- **交通頁** `#tickets`：要劃位的導言＋費用總覽、手繪線路圖（直式 SVG）、**訂票清單**（依截止日排序、倒數天數、打勾存檔）、
  **每日交通卡**（各段交通、要先訂／當天買／開車／步行標籤、要訣、訂票連結）、自駕須知（駕照、異地還車、ETC、停車場一覽）。
- **餐廳頁** `#resto`：B1 版面＝地圖（餐別顏色：午餐橘、晚餐藍、早餐點心綠；照片縮圖；靠太近合成群組）＋名單；依日期（時段）／依地區切換；口袋名單表單。
- **美食** `#food`：必吃料理卡片（`data-wiki` 由瀏覽器即時抓維基圖）。
- **花費頁** `#cost`：COST 產生，每人金額、未知標灰、同行人數 −／＋ 分攤租車停車。

## 手機 App 版（≤640px，獨立外殼 `#mapp`，和桌機完全不同的版面）
設計來源：Claude Design「Trip planning mobile app」1b 時間軸模板，Organic 配色（底 #f5ead8、強調 #c67139、橄欖綠 #7a8a5e）。
- **首頁**：大字倒數、天數・景點數・行李進度、航班、每日列表、**「現在」卡片**（旅途中顯示現在在哪一站、下一站倒數）、雨備開關。
- **行程**：週曆膠囊＋時間軸（時間｜依類型上色的軸點｜站名、類型膠囊、備註、右側縮圖），兩站之間交通藥丸；左右滑動換天；
  天氣格（點開看詳細）；點列開底部抽屜（下滑關閉）。旅途中自動捲到「現在」。
- **地圖**：當天路線圖（向量縮放 1–80 倍：雙指、拖曳、雙擊、＋－還原）、天氣徽章、可點的區域色塊、路線順序列表＋交通圖例；點標記一次聚焦、再點開抽屜。
- **清單**：行李清單勾選、篩選未打包、自行新增。
- **資訊**：分段「花費／景點／交通／餐廳」。景點＝地區色塊地圖 → 放大進子區 → 編號地圖＋已排入／候選名單。
- **雨備**：一顆按鈕切換整個 App 色調（陰天灰藍，0.55 秒淡入淡出），行程與地圖換成雨天版（沒有雨天版的天顯示提示）。
- **iOS 細節**：standalone 狀態列 `black-translucent`＋`#mapp::before` 色條、safe-area、`100lvh`、Safari theme-color 重放 meta、卡片下滑關閉。

## 離線版（PWA）
`sw.js`：網頁 network-first（3 秒逾時用快取、`cache:'no-cache'` 繞過 Pages 10 分鐘 HTTP 快取）、同源資源 cache-first、
維基 API network-first、維基圖片與 Google 字型 cache-first；網頁抓到縮圖網址後 `postMessage({type:'warm'})` 預存。
只在 http(s) 註冊。iPhone Safari 分享 →「加入主畫面」；Android Chrome →「安裝應用程式」。

## 刻意不做的
- **即時共用的清單／協作**：GitHub Pages 沒有伺服器。餐廳推薦改用「LINE 分享文字 → 主辦人收錄」。
- **道路網、手繪風地圖**：沒有圖資就不畫，避免捏造地理位置；改嵌官方手繪地圖（燈箱可放大）。
- **緊急資訊頁**：範例使用者去過日本很多次，不要。新行程可問使用者。

## 照片與影片
- 使用者在對話中貼圖 → `scripts/addphotos.py --html index.html <cardKey> <圖檔…>`（WebP q78、長邊 1000；第一張封面，橫式排前面）。
- 使用者截圖常帶 Google 鏡頭圖示、浮水印、網址字樣 → 嵌入前先用 PIL 裁掉（通常底部 8–9%），並告知使用者裁了什麼。
- 照片內容和卡片對不上（例：看起來是別的神社）就不放，問使用者。
- 影片放 YouTube 網址（使用者提供），本機 `file://` 開會出現錯誤 153（需要 referrer），放上 Pages 就正常。
